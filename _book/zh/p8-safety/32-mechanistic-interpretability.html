机械可解释性

一个训练好的 Transformer 是几千亿个数字，产出无人明确写下的行为。机械可解释性试图把这些数字读作计算：找出模型表示的特征、以及连接它们的电路，就像把二进制反编译回源代码那样。读完本章，你会明白单个神经元为什么很少只意味一件事，稀疏字典为什么成了拆开特征的主要工具，以及这个工具本身是否真的对路，为什么至今仍是一个悬而未决的问题。

意味一切的那个神经元

打开一个 Transformer，从最显然的地方入手。神经网络的基本单位是神经元，自然的期待是每个神经元都代表某一件事：这个对 Python 代码响应，那个对红色响应。早期视觉研究确实找到过几个这样的神经元。语言模型却不这么配合。戳一下 Transformer 里的某个神经元，它会同时对一大堆毫不相关的东西激活，既是曲线检测器、又是车轮、还是一行法语。这就叫多义性，是挡在朴素解释面前的那堵墙。如果你能读出来的单位本身就代表不止一个意思，读它便毫无所获。

墙的问题不在于模型没有概念，而在于模型的概念数远多于神经元数，它却把这些概念全装了进去。宽度为 ddd 的残差流只有 ddd 个正交方向，模型却像是在追踪成千上万个不同的特征。总得有什么让步。这些特征没法各占一个方向，于是只好彼此共享。本章的全部内容，就是把这种共享解开：从混在一起的激活中复原出模型用到的那些概念，再展示它们如何相互喂送、最终产生输出。这有什么用？第 33 章 会专门展开。只能盯着行为的监督是个瞎子，面对一个一直表现正常、直到某天不正常的模型，它无能为力；而能读到特征的监督，至少有机会在计划执行之前把它截下来。

所以本章围绕一个障碍、以及一波接一波试图攻克它的努力来组织。先讲两个想法，它们解释了这堵墙为什么存在、又怎样才能翻过去。然后是电路，它把复原出的特征转化为对行为的解释。再往后，是一场长达十年的军备竞赛，从手工描出的视觉滤波器，一路推进到生产级模型的因果图。接着是一场仍在进行的审判：这个领域的主要工具到底对不对。最后，坦诚清点这个工具至今留下的盲区。

攀越这堵墙的两个想法

脱离多义性靠的是两个想法：一个关于模型如何存储特征的假说，一个把它们复原出来的方法。

假说叫叠加（superposition）。模型表示的特征比维度还多，办法是给每个特征分配激活空间里的一个方向，再让这些方向相互重叠。它之所以行得通，是因为特征很稀疏：在任意一个词元上，数千种可能的特征里只有少数真正激活，于是模型能容忍那些极少同时打开的方向之间的干扰。Elhage 等在《Toy Models of Superposition》里给出了最干净的示范 (Elhage et al. 2022)：一个被硬塞着把 nnn 个稀疏特征压进少于 nnn 个维度的小自编码器，做的正是这件事，它把特征方向排成规则的几何结构，随稀疏度的变化在重构误差与干扰之间权衡。多义性在这幅图景里不是缺陷，而是模型借叠加装下超过神经元数量的特征时，投在外面的影子。

如果特征是沿方向、而非沿神经元存在的，那么正确的分析单位就是方向，正确的工具就是能找出这些方向的那个。这个工具叫字典学习，用稀疏自编码器（SAE）来实现 (Cunningham et al. 2023)。一个 SAE 接收某个模型激活 x∈Rdx \in \mathbb{R}^{d}x∈Rd，学出一个由 m≫dm \gg dm≫d 个特征方向组成的过完备字典，把 xxx 编码成一个稀疏的特征激活向量，再解码回来：

f=σ(Wencx+benc),x^=Wdecf+bdecf = \sigma(W_{\text{enc}} x + b_{\text{enc}}), \qquad \hat{x} = W_{\text{dec}} f + b_{\text{dec}} f=σ(Wenc​x+benc​),x^=Wdec​f+bdec​

训练目标是最小化重构误差加上一个稀疏惩罚，使得任何输入上只有 mmm 个特征里的少数被激活。WdecW_{\text{dec}}Wdec​ 的每一列就是复原出的一个特征方向。因为 mmm 大于 ddd，字典是过完备的：它有富余的空间给每个底层特征单独留一个槽位，哪怕原模型当初不得不把它们挤进 ddd 个拥挤的维度。SAE 复原出的特征，远比原始神经元更常是单义的，而这正是整件事的意义所在。

图 32.1 展示了让这套机制成立的那种双向的数字张力。模型把许多稀疏的真实特征压进残差流的 ddd 个共享方向，容忍那些极少同时激活的方向之间的干扰。SAE 把这个压缩反过来跑，将这个 ddd 维向量展开到 m≫dm \gg dm≫d 个槽位，让每个特征重新落回属于自己的方向。

从名词到动词：电路

特征本身只是名词。要解释行为，还需要动词，也就是把一个特征的激活传给另一个的那些连接。这就是电路。电路是模型计算的一个子图，几个特征加上它们之间的权重，共同实现某种可识别的算法。视觉之外最早被完整做出来的例子是归纳头（induction head），一个由两个注意力头组成的电路，实现这样一条规则：「如果词元 AAA 在上文较早的位置之后跟着 BBB，而现在我又看到了 AAA，那就预测 BBB。」Olsson 等人追踪了这个电路，并把它的形成与训练中的一次相变联系起来，这次相变恰好与上下文学习的兴起同步 (Olsson et al. 2022)。这个领域的目标，是对任意行为做归纳头为复制所做的那件事：给特征起名，给连接起名，再通过干预来检验这个解释。

让这个目标变难的有两件事，而它们方向相反、相互拉扯。给特征起名，需要一个只代表一件事的单位，可叠加从神经元手里夺走了它，字典学习则想把它夺回来。给连接起名，需要一个关于这些单位如何组合的模型，那就是电路。这个领域的历史，就是这两种需求彼此推着对方往前走的故事。

一场对抗这堵墙的军备竞赛

这条脉络从手工追踪的电路，到学出来的特征，再到因果图，每一步都被上一步的极限逼出来。

它始于视觉。Olah 等在 Distill 上的系列文章《Zoom In: An Introduction to Circuits》主张特征是真实的、连接它们的电路也是真实的，并在卷积网络里手工把两者都展示了出来 (Olah et al. 2020)。要把这套方法带到 Transformer 上，需要一套针对该架构的代数。Elhage 等的《A Mathematical Framework for Transformer Circuits》提供了它 (Elhage et al. 2021)：残差流是一条共享的通信通道，每一层都从中读、又向其中写；注意力头是在位置之间搬运信息的操作；再加上让多个头组成多步电路的组合规则。归纳头就是那套框架解释的第一个重大结果。

然后撞上了墙：手工追踪没法扩展，而叠加意味着你想追踪的那些神经元本就是多义的。《Toy Models of Superposition》给这个障碍起了名 (Elhage et al. 2022)。脱身之法是不再读神经元，转而去学特征。Cunningham 等的《Sparse Autoencoders Find Highly Interpretable Features in Language Models》(Cunningham et al. 2023) 和 Anthropic 的《Towards Monosemanticity》(Bricken et al. 2023) 在同一时期落到了同一个想法上：在模型激活上训练一个 SAE，复原出的字典比神经元基底可解释得多。Bricken 等在一个带 512 个神经元 MLP 的单层 Transformer 上工作，展示了字典特征能挑出清晰的概念，比如阿拉伯文字或 DNA 序列，而没有哪个单独的神经元能干净地抓住它们。

悬而未决的问题是：这一切能否经得起规模的考验。《Scaling Monosemanticity》把 SAE 推到了 Claude 3 Sonnet 这个生产级模型上，在它的中间层残差流上训练字典，复原出抽象的、跨语言、跨模态的特征 (Templeton et al. 2024)，其中就包括那个金门大桥特征：把它钳制在打开状态，就得到了那个把每一次对话都引向大桥的「Golden Gate Claude」。比这场演示更重要的是这次干预本身：它表明这些特征是因果性的，而不只是相关的。与此同时，SAE 的工程也在收紧。Gao 等的《Scaling and Evaluating Sparse Autoencoders》(Gao et al. 2024) 用一个 top-kkk 激活替换了软性的 L1 惩罚，直接固定住活跃特征的数量，既免去了一桩调参的烦恼，又压低了死潜元的数量，还给出了把字典规模、稀疏度与重构联系起来的清晰扩展律。图 32.2 勾画了这层关系：每个词元上更多的活跃潜元，换来更低的重构误差；更大的字典，把整条前沿往下推；而稀疏度这根轴的两端，藏着本章后面会回头来谈的失效模式。

下面扫一遍 top-kkk 稀疏度，看着重构误差先一路下降，随后一旦 kkk 达到真实的活跃特征数就趋平，剩下一段无论再加多少潜元都消不掉的非零残余。

import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(0)
d, m, n_true = 32, 96, 6        # residual width d, dictionary slots m, true active features
D = rng.standard_normal((m, d))
D /= np.linalg.norm(D, axis=1, keepdims=True)

codes = np.zeros((300, m))      # each token uses only n_true of the m features
for c in codes:
    idx = rng.choice(m, n_true, replace=False)
    c[idx] = rng.standard_normal(n_true)
X = codes @ D + 0.15 * rng.standard_normal((300, d))   # activations are only nearly sparse
base = np.mean(X ** 2)

ks, frac = list(range(0, 13)), []
for k in ks:
    f = codes.copy()
    if k == 0:
        f[:] = 0
    else:
        thr = np.sort(np.abs(f), axis=1)[:, -k][:, None]
        f = np.where(np.abs(f) >= thr, f, 0.0)         # keep only the k largest latents
    frac.append(np.mean((X - f @ D) ** 2) / base)

plt.plot(ks, frac, "o-")
plt.axvline(n_true, ls="--", color="gray", label=f"true sparsity = {n_true}")
plt.xlabel("k active latents per token")
plt.ylabel("fraction of variance unexplained")
plt.legend(); plt.title("Top-k reconstruction: drops, then plateaus on a residue")
plt.show()
print("unexplained at k=0,3,6,12:", [round(frac[i], 3) for i in (0, 3, 6, 12)])

最新的一步，把名词和动词重新拼回了一起。Anthropic 在 2025 年的工作，《Circuit Tracing》(Ameisen et al. 2025) 和《On the Biology of a Large Language Model》(Lindsey et al. 2025)，构造出归因图：它把模型的 MLP 替换成跨层转码器，也就是一种从某一层读入、向之后所有层写出的稀疏可解释特征，然后针对单个提示，追踪穿过这些特征的线性因果路径。结果是一张图，节点是特征，边是因果影响，是针对一个输入的局部电路图。在 Claude 3.5 Haiku 上研究时，这些图揭示出多步推理、在押韵中提前规划、以及跨语言共享的机制 (Lindsey et al. 2025)。

图 32.3 追踪了这条演进路线，其中每一步都被上一步的极限逼出来。

这套方法在实践中如何运转，是很机械的，值得照着轮廓看一遍。先在模型的某一处采集大量激活，可以是某一层之后的残差流，也可以是某个 MLP 的隐藏层激活。在这些激活上训练字典。用一个 top-kkk 编码器，前向传播很小：

# x: model activation, shape (batch, d)
pre = x @ W_enc + b_enc            # (batch, m), m >> d
f   = topk(pre, k)                  # keep k largest, zero the rest
x_hat = f @ W_dec + b_dec           # reconstruct
loss = mse(x_hat, x)                # no separate L1 term: k fixes sparsity

固定的 kkk 免去了 L1 形式逼你去调的那个稀疏系数，这正是 top-kkk SAE 取代旧式软惩罚的实际原因 (Gao et al. 2024)。训练完成后，字典的每一列都是一个候选特征。你解读它的办法，是收集最能激活它的那些输入，读出其中的模式，而关键一步在于：把这个特征钳制在打开或关闭状态，看着输出随之移动，以此检验你的解读。一个你没法用来操控的特征，就是一个你还没真正理解的特征。归因图把同样的纪律推广到整个计算：用训练好的转码器替换 MLP，跑一个提示，读出活跃特征之间的因果图，再通过扰动节点、确认其下游效应来验证每一条边 (Ameisen et al. 2025)。

稀疏自编码器的审判

这场军备竞赛已经把这个领域带到了一个生产级模型和一张因果图，但它并没有了结那个核心的方法论问题。整套翻墙之法，都押在一个赌注上：字典学习就是读取叠加的正确方式。这个赌注如今正在受审。

争议所在稀疏自编码器到底是正确的可解释性原语，还是一条容易产生伪影的弯路，这一点正被激烈争论。反对一方手里有几个具体的结果。Kantamneni 等的《Are Sparse Autoencoders Useful? A Case Study in Sparse Probing》[@kantamneni2025useful] 发现，在下游探测任务上，一旦把简单基线做强，SAE 特征就很难再胜过它们，这让人怀疑它的实际收益。Chanin 等记录了特征吸收的现象：「以 L 开头」这样的一般特征，会在「lion」这样的特定词元上沉默下来，因为一个更具体的特征把它吞掉了，于是字典表面上的干净，部分是训练目标造成的伪影 [@chanin2024absorption]。还有人主张，L1 稀疏惩罚会把 SAE 推向去学习频繁出现的组合，而不是真正中介计算的那些原子特征，并且转码器在可解释性上胜过 SAE（arXiv:2501.18823）。辩护一方以 Anthropic 的可解释性团队、以及扩展和归因这些工作的作者为核心，他们反驳说：SAE 是一项可以改进的工程，而不是一条死路；像 Golden Gate Claude 那样的因果干预，证明了这些特征是真实的；归因图也已经产出了单凭裸探测做不到的机械解释。分歧不在于叠加是否真实，而在于字典学习是不是我们读取它的正确方式。
约束箭头叠加是 @sec-transformer-architecture 那个架构层面的事实，它支配着本章里每一个工具的形状。正因为残差流装下了比维度更多的特征，任何直接读神经元的方法都行不通，这个领域于是被迫走向过完备字典学习。模型如何存储信息的这一性质，定下了我们如何读取它的整套方法栈。

字典留下了什么

本章里的每一份收益，都要用一份相应的代价换来，把这些代价点清楚，正是诚实看待上面那场审判的办法。

  • 单义性对完备性。 稀疏性换来了干净、单义的特征，可字典只能复原它被设定好、被训练去寻找的那些特征。把稀疏性推得太狠，特征就会分裂、或被彼此吸收；推得太软，它们又会重新变得多义。SAE 对激活的重构并不完美，而那道缝隙，也就是重构误差，恰好是字典没能解释的那部分模型计算。
  • 忠实性对可解释性。 一个替换掉模型一部分的转码器或 SAE，它可解释到什么程度，取决于它对原本计算保持忠实到什么程度。归因图把这层权衡摆到了明面上：它冻结注意力、近似 MLP，于是这张图讲的是一个可读的故事，可故事里的那个模型，已经不完全是你部署的那个了。
  • 局部对全局。 一张归因图解释的是一个提示。一套特征字典描述的是一个模型在某个训练检查点的样子。两者都还给不出一份全局的、可复用的说明，说清模型在你没追踪过的输入上会做什么，而这恰恰是监督最终想要的东西。
  • 投入对覆盖。 读一个电路是缓慢的人工活儿。自动解释，也就是用一个模型来给特征打标签，把这份劳动的规模放大了，却也引入了标注者的错误，而且这个领域至今没有一个公认的指标，能判定一个特征到底有没有被正确理解。

这些失效模式都很具体，每一种都是字典在「自己有多干净」这件事上撒的一个谎。死潜元是那些从不激活、什么也学不到的字典特征，白白占着容量。死潜元与过度激活的潜元加在一起，把你推向 top-kkk 和谨慎的初始化 (Gao et al. 2024)。特征分裂会塞给你好几个狭窄的特征，而模型本来只有一个；吸收则把一个一般特征藏进一个特定特征里，于是字典看上去比模型本身更干净 (Chanin et al. 2024)。而重构误差也不是可以忽略不计的噪声：它是那段未被解释的残余，是你的字典没能捕获的那部分计算，一个一边报告高可解释性、一边留着大量误差的方法，解释到的其实比它宣称的要少。这堵墙，到头来从未被彻底翻越。本章给出的，是对我们已经爬到哪里的一份克制的盘点，以及对剩下那段距离的一份诚实的判读。
